# Mifos Self Service Plugin — Documentation Docker Setup

Production-ready Docker setup for serving the Astro + Starlight documentation
site behind Nginx. Target domain: **https://docs.mifos.community**

## Prerequisites

- Docker and Docker Compose installed
- The documentation source (this directory) with `dist/` generated by
  `npm run build`

## File Overview

| File | Purpose |
|------|---------|
| `Dockerfile` | Multi-stage build: Node.js builds the site, Nginx Alpine serves it |
| `docker/nginx.conf` | Production Nginx config (security headers, compression, caching, SPA routing) |
| `docker-compose.yml` | Compose service definition with healthcheck, Traefik labels, resource limits |
| `.dockerignore` | Files excluded from the Docker build context |
| `README-DOCKER.md` | This file |

## Quick Start

### 1. Build the documentation site

From the documentation project root:

```bash
npm ci
npm run build
```

This generates the static site in `dist/`.

### 2. Build and run with Docker Compose

```bash
docker compose up --build
```

The site will be available at **http://localhost:80**.

### 3. Stop

```bash
docker compose down
```

## Production Deployment

### Behind a reverse proxy (TLS terminated externally)

The container listens on port 80 and expects TLS termination at the edge
(e.g., Traefik, Caddy, AWS ALB, Cloudflare Tunnel). Set the `VIRTUAL_HOST`
environment variable in `docker-compose.yml` if your proxy uses it.

```bash
docker compose up -d
```

Then point `docs.mifos.community` at the host running this container.

### With Traefik + automatic HTTPS (Let's Encrypt)

Uncomment the Traefik labels in `docker-compose.yml` and ensure your Traefik
instance has a `le` certificate resolver configured:

```yaml
labels:
  - "traefik.enable=true"
  - "traefik.http.routers.docs.rule=Host(`docs.mifos.community`)"
  - "traefik.http.routers.docs.entrypoints=web"
  - "traefik.http.routers.docs.tls=true"
  - "traefik.http.routers.docs.tls.certresolver=le"
  - "traefik.http.services.docs.loadbalancer.server.port=80"
```

Then:

```bash
docker compose up -d
```

Traefik will obtain a certificate and serve `https://docs.mifos.community`.

### With Caddy

A minimal Caddyfile:

```
docs.mifos.community {
    reverse_proxy docs:80
}
```

## Healthcheck

The container exposes `/healthz` returning `200 OK`. Docker Compose includes
a healthcheck that polls this endpoint every 30 seconds.

```bash
curl -f http://localhost:80/healthz
```

## Security Notes

- Runs as non-root `nodejs` user for Nginx worker processes
- Security headers: `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`,
  `Referrer-Policy`, `Permissions-Policy`, CSP
- Gzip + Brotli compression enabled
- Long-term caching for hashed assets (`_astro/`), short cache for HTML
- Hidden files, dot-directories, and source/config files denied

## Environment Variables

| Variable | Example | Purpose |
|----------|---------|---------|
| `NGINX_HOST` | `docs.mifos.community` | Informational; used by some reverse proxies |
| `VIRTUAL_HOST` | `docs.mifos.community` | nginx-proxy / Traefik virtual host |
| `VIRTUAL_PORT` | `80` | Backend port for reverse proxy |

Override at runtime:

```bash
docker compose -f docker-compose.yml up \
  -e NGINX_HOST=docs.mifos.community
```

## Resource Limits (optional)

Uncomment in `docker-compose.yml` for production:

```yaml
mem_limit: 256m
cpus: '0.5'
```

## Building the Image Directly

Without Docker Compose:

```bash
docker build -t mifos-docs:latest .
docker run -p 80:80 mifos-docs:latest
```

## Multi-Architecture

The `node:20-alpine` and `nginx:1.27-alpine` base images support `linux/amd64`
and `linux/arm64`. For multi-arch builds, use `docker buildx`:

```bash
docker buildx build --platform linux/amd64,linux/arm64 -t mifos-docs:latest .
```
