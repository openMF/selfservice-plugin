# AI Agent Guidance — Mifos Self Service Plugin Documentation

This file helps AI agents and coding assistants understand, navigate, and contribute to this Starlight documentation site.

## Project Purpose
Documentation site for the Mifos Self Service Plugin — a Spring Boot plugin that extends Apache Fineract with customer-facing self-service banking APIs under `/v1/self/...`.

## Site Structure
```
/src/content/docs/
  index.mdx                              # Landing page
  getting-started/                       # Introduction, what-is, architecture, prerequisites
  user-guide/
    installation/                        # Build from source, Docker, Tomcat, pre-built JARs
    configuration/                       # Basic settings, notifications, step-up OTP
    api-overview/                        # One page per capability area
    api-reference/                       # Endpoints summary, Postman/Bruno, Swagger/OpenAPI
    security-best-practices.mdx
  developer-guide/                       # Setup, structure, standards, testing, migrations, contributing, troubleshooting
  reference/                             # Config properties, permissions, changelog, license
/public/
  llms.txt                               # AI-agent overview of the site
  robots.txt                             # Crawler policy (allows AI agents)
  styles/design-system.css               # Premium design tokens & overrides
/astro.config.mjs                        # Starlight config (title, sidebar, social, head, site)
/package.json                            # Astro + Starlight dependencies
```

## How to Read a Page
- All pages are MDX with frontmatter: `title`, `description`
- Pages may import Starlight components: `Card`, `CardGrid`, `Aside`, `Tabs`, `TabItem`, `LinkGroup`
- Code blocks are fenced with language tags (`bash`, `sql`, `yaml`, `java`, `json`)
- Tables are standard Markdown/HTML
- `Aside` supports `type`: `note`, `tip`, `caution`, `danger` (NOT `warning`)

## How to Add a New Page
1. Create `src/content/docs/<section>/<page>.mdx` with frontmatter
2. Add a sidebar entry in `astro.config.mjs` with the matching `slug`
3. Run `npm run build` to verify
4. For pages using Starlight components, use `.mdx` extension

## Key Conventions
- Endpoints: all under `/v1/self/`
- Staff-facing user admin: under `/v1/selfservice/users`
- Plugin JAR: `target/selfservice-plugin-1.16.0-SNAPSHOT.jar`
- Fineract version: `1.16.0-SNAPSHOT` (`develop` branch)
- Java: 25 · Spring Boot: 4
- Build command: `./mvnw clean package -Dmaven.test.skip=true`
- Per-tenant config lives in `c_external_service_properties` (not env vars)

## AI-Agent Friendly Files
- `public/llms.txt` — concise site overview for LLM consumers
- `public/robots.txt` — crawler policy (allows AI agents)
- `/sitemap.xml` — auto-generated by Starlight when `site` is set
- Pagefind search index — built-in full-text search at build time

## Do Not
- Do not invent APIs, configuration keys, or capabilities not present in the source repo
- Do not use `type="warning"` on `<Aside>` — use `caution`
- Do not put `template: splash` on content pages (only `index.mdx`)
- Do not use array format for Starlight `head` config — use object form `{ tag, rel, href }`
