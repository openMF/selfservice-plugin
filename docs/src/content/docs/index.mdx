# Mifos Self Service Plugin

A Spring Boot plugin that extends [Apache Fineract](https://fineract.apache.org/) to provide **customer-facing self-service banking APIs** under `/v1/self/...`.

It lets customers register, authenticate, view their accounts, transfer funds, and manage their financial products — all without staff intervention. This is a **plugin**, not a standalone application: it ships as a JAR you drop into your existing Fineract deployment.

## Quick Start

Build the plugin from source and deploy it into Fineract:

```bash
git clone https://github.com/openMF/selfservice-plugin.git
cd selfservice-plugin
./mvnw clean package -Dmaven.test.skip=true
```

```bash
# Copy into a Fineract deployment
cp target/selfservice-plugin-*.jar /opt/fineract/plugins/
java -Dloader.path=/opt/fineract/plugins/ -jar fineract-provider.jar
```

Endpoints are then available at `https://<fineract-host>/fineract-provider/v1/self/...`.

## Tech Stack

| Layer | Technology |
|---|---|
| Language | Java 25 |
| Framework | Spring Boot 4 · Spring Security (Basic Auth + OAuth2) |
| API | JAX-RS · Swagger / OpenAPI |
| Data | JPA / EclipseLink · Liquibase (multi-tenant) |
| Runtime | Apache Fineract 1.16.0-SNAPSHOT |
| Database | PostgreSQL or MySQL (managed by Fineract) |

## Who Is This For

- **Banks & fintechs** — offer customers a modern digital banking experience without replacing your core.
- **Mobile / web app developers** — integrate self-service banking into your customer app via REST APIs.
- **Platform engineers** — deploy a lightweight JAR plugin into your existing Fineract instance.
- **Contributors** — extend endpoints, add features, and ship back to the community.
