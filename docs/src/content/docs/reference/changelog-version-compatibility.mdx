## History

This plugin was extracted from the Apache Fineract codebase. The self-service functionality was originally part of Fineract core and was removed to keep Fineract modular. This repository continues that work as a standalone, community-maintained plugin under the Mifos Initiative.

## Upgrading

1. Build the new plugin JAR from source.
2. Deploy it into your Fineract instance (Docker or Tomcat).
3. Restart Fineract — Liquibase migrations run automatically against every tenant.
4. Verify endpoints are available at `/v1/self/...`.
