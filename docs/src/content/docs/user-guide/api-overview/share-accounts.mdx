# Share Accounts

Endpoints under `/v1/self/shareaccounts` for managing share accounts.

## Endpoints

| Endpoint | Method | Description |
|---|---|---|
| `/v1/self/shareaccounts` | `GET` | List share accounts |
| `/v1/self/shareaccounts` | `POST` | Apply for a new share account |
| `/v1/self/shareaccounts/{accountId}` | `GET` | Get share account details |
| `/v1/self/products/share` | `GET` | List available share products |

## What You Can Do

- View share account holdings
- Apply for share products
