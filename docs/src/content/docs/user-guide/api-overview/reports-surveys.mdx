# Reports & Surveys

Endpoints for running pre-configured reports and participating in surveys.

## Endpoints

| Endpoint | Method | Description |
|---|---|---|
| `/v1/self/runreports` | `GET` | Run self-service reports |
| `/v1/self/runreports/{reportName}` | `GET` | Run a specific report |
| `/v1/self/surveys` | `GET` | List surveys (SPM) |
| `/v1/self/surveys/scorecards` | `GET` | List survey scorecards |
| `/v1/self/surveys/scorecards` | `POST` | Submit a scorecard |

## What You Can Do

- Run pre-configured financial reports scoped to your account
- Participate in surveys and view scorecards
