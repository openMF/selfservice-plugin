# Products Catalog

Endpoints for browsing available banking products.

## Endpoints

| Endpoint | Method | Description |
|---|---|---|
| `/v1/self/savingsproducts` | `GET` | List available savings products |
| `/v1/self/loanproducts` | `GET` | List available loan products |
| `/v1/self/products/share` | `GET` | List available share products |

## What You Can Do

- Browse savings, loan, and share products offered by the bank
- View product details before applying
